# Довідник правил озвучення (українська мова)

## 1. Кількісні числа

- Рід числівника за іменником: *один/одна/одне*, *два/дві*.
  «1 доба» → «одна доба», «2 тонни» → «дві тонни», «2 відра» → «два відра».
- Форма іменника: 1, 21, 31… → однина Н.в.; 2–4, 22–24… → множина Н.в.;
  5–20, 25–30… та 11–14 → Р.в. множини.
- Після прийменників числівник відмінюється разом з іменником:
  | Відмінок | Приклад |
  |---|---|
  | Р.в. | до п'яти осіб, понад двадцять трьох кілометрів, близько тисячі |
  | Д.в. | п'ятьом пораненим, двом бійцям |
  | О.в. | з трьома бійцями, п'ятьма машинами |
  | М.в. | на двох позиціях, у п'яти випадках |
- 1000 → «тисяча», 1 000 000 → «мільйон» (без «одна/один»).
- Великі округлі значення можна спростити для слухача, якщо точність не
  критична: «1 247 000» → «близько одного мільйона двохсот п'ятдесяти тисяч» —
  **тільки з дозволу користувача**.
- Телефони читати групами: «+380 67 123 45 67» → «плюс три вісім нуль,
  нуль шість сім, сто двадцять три, сорок п'ять, шістдесят сім».
- Номери документів, жетонів, серійні номери — по цифрах або групами по 2–3.

## 2. Дробові числа

- «3,5» → «три цілих п'ять десятих»; «1,5» → «одна ціла п'ять десятих».
- Іменник після дробу — **Р.в. однини**: «2,5 кілометра», «0,9 відсотка».
- У розмовному стилі допустимо: «3,5» → «три з половиною», «0,5» → «половина»,
  «1,25» → «одна ціла двадцять п'ять сотих» або «одна і чверть».
- Звичайні дроби: ½ — «половина», ⅓ — «третина», ¼ — «чверть»,
  «2/3» — «дві третіх».

## 3. Порядкові числа, дати, роки

- «5-й», «3-го», «21-ша» → «п'ятий», «третього», «двадцять перша».
- Дата: «13.10.2026» → «тринадцятого жовтня дві тисячі двадцять шостого
  року» (Р.в., відповідає на «коли?»); у заголовку — «тринадцяте жовтня…».
- Рік: «у 1944 р.» → «у тисяча дев'ятсот сорок четвертому році»;
  «1944 р.» → «тисяча дев'ятсот сорок четвертого року»; «2000» →
  «двохтисячний» (Правопис 2019).
- Десятиліття: «1940-ві», «40-ві рр.» → «сорокові роки».
- Століття: «XX ст.» → «двадцятого століття»; «у III ст. до н. е.» → «у
  третьому столітті до нашої ери».
- Діапазон років: «1941–1945 рр.» → «тисяча дев'ятсот сорок перший –
  тисяча дев'ятсот сорок п'ятий роки» (Н.в.) / «…першого – …п'ятого років»
  (Р.в.) / «у …першому – …п'ятому роках» (М.в.).
- Час: «14:30» → «чотирнадцята тридцять»; «о 14:30» → «о чотирнадцятій
  тридцять»; «06:05» → «шоста нуль п'ять»; «14:00» → «чотирнадцята нуль-нуль»
  або «чотирнадцята година».

## 4. Одиниці виміру й символи

| Запис | Озвучення |
|---|---|
| % | відсоток / відсотки / відсотків / відсотка (після дробу) |
| °C, ℃ | градус(и, ів, а) Цельсія |
| мм рт. ст. | міліметрів ртутного стовпа |
| уд/хв | ударів за хвилину |
| мг/кг | міліграмів на кілограм |
| км/год | кілометрів на годину |
| 10×20 см | десять на двадцять сантиметрів |
| ± | плюс-мінус |
| ≈, ~ | приблизно |
| ≤ / ≥ | не більше / не менше |
| № | номер |
| § | параграф |
| / (між словами) | «або», «на», «за» — за змістом |
| — у таблиці | немає даних |

Діапазон з одиницею: «5–7 км» → «від п'яти до семи кілометрів».
Діапазон без одиниці: «1–2 таблетки» → «одна-дві таблетки».

## 5. Абревіатури

Три способи — обирати за усталеною вимовою:

1. **Розшифрувати** (коли вимова побуквено незрозуміла слухачеві):
   АТ — артеріальний тиск; ЧСС — частота серцевих скорочень; ЧДР — частота
   дихальних рухів; SpO₂ — сатурація; в/в, в/м, п/ш — внутрішньовенно,
   внутрішньом'язово, підшкірно; ККУ — Кримінальний кодекс України;
   КПК — Кримінальний процесуальний кодекс; БпЛА — безпілотний літальний
   апарат; ТЦК — територіальний центр комплектування; ЧМТ — черепно-мозкова
   травма; ПХО — первинна хірургічна обробка; СМЕ — судово-медична експертиза.
2. **Читати як слово** (акроніми, що вимовляються складами): НАТО, ООН,
   ЗУНР, УПА («у-пе-а» — краще побуквено), ДБР («де-бе-ер»), РЕБ («реб»).
3. **Побуквено з назвами літер** (усталені ініціальні): ЗСУ — «зе-се-у»,
   СБУ — «есбеу», США — «сеша», МОЗ — «моз», ЄС — «є-ес». Для TTS
   записувати так, як має прозвучати: «зе-се-у».

Правило першої згадки: у довгому тексті при першій появі — повна назва,
далі — коротка вимовна форма.

Позивні, назви підрозділів і населених пунктів — **не змінювати**, лише
за потреби поставити наголос.

## 6. Таблиці

Слухач не бачить сітки, тому таблицю треба **переказати**:

1. Вступ: що в таблиці й скільки рядків («У таблиці — показники пораненого
   за двома замірами»).
2. Для малих таблиць (до 4–5 рядків, 2–4 стовпці) — прозою по рядках:
   «О шостій сорок частота серцевих скорочень становила сто двадцять чотири,
   о сьомій десять — сто вісім».
3. Для порівняльних — групувати за змістом, а не по клітинках:
   «Найвищий показник — …, найнижчий — …».
4. Для великих таблиць — висновок + 3–5 ключових значень + фраза «Повна
   таблиця доступна в текстовій версії». Про стиснення повідомити користувача.
5. Порожні клітинки — «немає даних»; одиниці — один раз, якщо спільні.

## 7. Списки, розмітка, посилання

- Маркований список → окремі речення або перелік через кому з «і» перед
  останнім. Нумерований → «по-перше, …; по-друге, …» або «Пункт перший: …».
- Заголовок → окреме речення з крапкою (пауза).
- Жирний/курсив, `код`, emoji, `#`, `*`, `|` — прибрати.
- URL → «посилання на сайт Вікіпедії» або прибрати; e-mail →
  «ім'я собака домен крапка ua» лише якщо його справді треба продиктувати.
- Виноски, дужки, лапки-цитати → окремим реченням: «Цитую: …».

## 8. Паузи й інтонація

- Крапка — повна пауза; кома — коротка; тире — смислова; «…» — затягнута.
- Між розділами — порожній рядок (більшість рушіїв робить довшу паузу).
- SSML (за потреби): `<break time="500ms"/>`, `<say-as interpret-as="cardinal">`
  не використовувати — числа вже розгорнуті; `<emphasis>` — для ключових
  слів; `<sub alias="зе-се-у">ЗСУ</sub>` — альтернатива ручній заміні.
- Наголос: знак U+0301 після голосної (за́мок) — лише для омографів і
  рідкісних власних назв.
