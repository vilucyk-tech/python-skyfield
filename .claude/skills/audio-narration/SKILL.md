# Аудіоозвучення тексту

Мета: отримати текст, який синтезатор мовлення або диктор прочитає **дослівно й
без помилок**: жодних цифр, символів, скорочень, таблиць чи розмітки — лише
слова, що звучать природно, з правильними відмінками й паузами.

## Порядок роботи

1. **Визначити параметри** (якщо не сказано — обрати типові, не питати):
   - мова: українська (для інших мов застосовувати ті самі принципи вручну);
   - формат виходу: чистий текст (типово) або SSML, якщо користувач назвав
     рушій із підтримкою SSML (Azure, Google, ElevenLabs, Amazon Polly);
   - стиль: нейтральний дикторський; для військових/медичних звітів — стислий.

2. **Перший прохід скриптом** (детермінована частина):
   ```bash
   python3 .claude/skills/audio-narration/scripts/normalize_uk.py вхід.md --report > вихід.txt
   ```
   або `- ` для stdin. `--report` виводить у stderr місця для ручної вичитки
   (залишкові цифри, абревіатури, латиниця, символи). `--selftest` перевіряє
   сам скрипт.

3. **Вичитка вручну** — обов'язкова; скрипт не бачить контексту. Перевірити:
   - **узгодження роду й відмінка** числівника з іменником, якого немає в
     таблиці одиниць: «2 людини» → «дві людини», «до 5 осіб» → «до п'яти осіб»,
     «з 3 бійцями» → «з трьома бійцями»;
   - **дати в потрібному відмінку**: скрипт дає родовий («тринадцятого
     жовтня»); у заголовку чи після «за» може знадобитися називний/знахідний
     («Звіт за тринадцяте жовтня»);
   - **абревіатури**: розшифрувати або залишити як вимовне слово — див.
     `references/rules.md`, розділ «Абревіатури»;
   - **латиниця й назви**: транслітерувати або перекласти (`wikipedia.org` →
     «Вікіпедія»), латинські терміни — українською вимовою;
   - **наголоси** в омографах (за́мок/замо́к, ві́кна/вікна́, му́ка/мука́) — позначити знаком
     наголосу (U+0301) лише там, де можлива помилка;
   - **ритм**: речення до ~25 слів; довгі — розбити. Дужки й примітки винести
     в окреме речення або прибрати.

4. **Таблиці** — скрипт робить базову версію («Таблиця. Стовпці: … Рядок: …»).
   Переписати змістовно за правилами з `references/rules.md` → «Таблиці»:
   для 2–4 рядків — суцільна проза; для великих таблиць — висновок + ключові
   значення, а не зачитування кожної клітинки.

5. **Фінальна перевірка**: у тексті не лишилося цифр, `%`, `/`, `№`, `°`,
   `*`, `#`, `|`, URL, emoji. Прочитати текст «уголос» подумки: чи зрозумілий
   він без зору?

## Ключові правила (коротко)

| Записано | Озвучити |
|---|---|
| 3,5 км | три цілих п'ять десятих кілометра |
| 15 % | п'ятнадцять відсотків |
| 5–7 хв | від п'яти до семи хвилин |
| 13.10.2026 | тринадцятого жовтня дві тисячі двадцять шостого року |
| у 1941–1945 рр. | у тисяча дев'ятсот сорок першому – тисяча дев'ятсот сорок п'ятому роках |
| XX ст. | двадцятого століття |
| о 14:30 | о чотирнадцятій тридцять |
| АТ 120/80 | артеріальний тиск сто двадцять на вісімдесят |
| -5 °C | мінус п'ять градусів Цельсія |
| № 3, 2-й | номер три, другий |
| і т. д. | і так далі |

Повний довідник: `references/rules.md` (числа, дати, одиниці, абревіатури
військові/медичні/юридичні, таблиці, списки, SSML, паузи).

## Чого не робити

- Не змінювати зміст, факти й числові значення — лише форму запису.
- Не скорочувати текст без прохання (крім стиснення великих таблиць, про що
  сказати користувачеві).
- Не лишати змішаних форм на кшталт «5 кілометрів» або «п'ять км».
- Не вигадувати розшифровку незнайомої абревіатури — запитати або залишити
  побуквено й позначити в коментарі.

## Результат

Видати користувачеві готовий текст для озвучення (у файлі, якщо текст
довгий), а під ним — короткий перелік рішень, що вимагали судження
(розшифровані абревіатури, стиснуті таблиці, змінені відмінки).
